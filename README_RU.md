# SecureEWS v0.7.3 — публичный релиз

SecureEWS оценивает образовательные системы раннего предупреждения как инструменты поддержки решений педагогов. Практический вопрос исследования: можно ли использовать меньше фоновой информации о студенте, сохранив полезность списков, которые преподаватель, консультант или служба поддержки действительно успевают рассмотреть.

Релиз сопровождает статью **“Evaluating Data-Minimized Early-Warning Systems for Educator Decision Support: Evidence Across Review Capacities and Educational Stages.”** В версии 0.7.2 использованы окончательные авторские редакции двух поясняющих схем. Зафиксированные расчёты, численные результаты и цепочка происхождения данных не изменены.

## Что важно для практики

- Модель оценивалась при возможности проверить 5%, 10%, 20% или 30% учебной группы, а не только по общей точности.
- Точечное исключение пола/гендера не дало семейно-скорректированного изменения полезности списков в трёх наборах данных при исследованных условиях.
- Исключение социально-экономической и семейной информации ухудшало общие показатели в OULAD и UCI 697 и отдельные рабочие списки.
- Вывод зависел от этапа обучения и реальной пропускной способности сотрудников.
- В небольших выборках UCI 320 эффект исключения данных остался неопределённым.
- Исключённые признаки частично восстанавливались из других записей. Удаление поля — мера управления данными, но не доказательство исчезновения всей связанной информации.

Результаты не доказывают эквивалентность моделей, справедливость, приватность или причинное улучшение обучения. Следующий необходимый шаг — перспективная оценка с участием педагогов и студентов.

## Состав

- код, зафиксированный протокол и unit tests;
- агрегированные результаты и хешированные bootstrap draws;
- воспроизводимые таблицы и рисунки;
- финальные MDPI article/Supplementary Materials sources и PDF в `paper/mdpi_submission/`;
- manifest, отчёты проверки и metadata для GitHub/Zenodo.

Внутренние номера вычислительных фаз сохранены только в путях и машинных файлах для воспроизводимости. В публичный пакет не входят исходные и обработанные построчные данные, индивидуальные predictions, обученные модели, полный private clean-room и производные XuetangX.

## Проверка

```powershell
py -3.12 -m pip install -r requirements.txt
py -3.12 scripts\make_public_manifest.py
py -3.12 scripts\verify_public_release.py
py -3.12 scripts\build_release_zip.py
py -3.12 scripts\verify_release_zip.py
```

Все проверки должны вернуть `PASS`.

## Статья и Supplementary Materials

- `paper/mdpi_submission/outputs/SecureEWS_MDPI_article_v6.pdf` — основная статья;
- `paper/mdpi_submission/outputs/SecureEWS_MDPI_supplement_v6.pdf` — отдельные Supplementary Materials;
- самостоятельные LaTeX source trees для загрузки в MDPI.

В статье есть Appendix A с понятным переводом метрик на язык организационных решений, а также две схемы, связывающие дизайн исследования и результаты с практикой педагогов. Детальный вычислительный материал сохранён в отдельном supplement, чтобы основной текст оставался читаемым. Оба PDF собраны из приложенных исходников и визуально проверены постранично. Данные для цитирования находятся в `CITATION.cff`, metadata для Zenodo — в `.zenodo.json` и `zenodo_metadata.json`.
